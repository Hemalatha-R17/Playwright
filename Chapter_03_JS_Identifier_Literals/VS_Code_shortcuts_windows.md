# VS Code Shortcuts — Windows

## General
| Action | Shortcut |
|--------|----------|
| Command Palette | `Ctrl + Shift + P` |
| Quick Open | `Ctrl + P` |
| Settings | `Ctrl + ,` |
| Keyboard Shortcuts | `Ctrl + K` `Ctrl + S` |

## Editing
| Action | Shortcut |
|--------|----------|
| Cut line | `Ctrl + X` |
| Copy line | `Ctrl + C` |
| Move line up/down | `Alt + ↑` / `Alt + ↓` |
| Copy line up/down | `Shift + Alt + ↑` / `Shift + Alt + ↓` |
| Insert line below | `Ctrl + Enter` |
| Insert line above | `Shift + Ctrl + Enter` |
| Delete line | `Ctrl + Shift + K` |
| Indent / Outdent | `Ctrl + ]` / `Ctrl + [` |
| Go to matching bracket | `Ctrl + Shift + \` |
| Toggle comment | `Ctrl + /` |
| Block comment | `Shift + Alt + A` |

## Multi-Cursor & Selection
| Action | Shortcut |
|--------|----------|
| Add cursor | `Alt + Click` |
| Add cursor above/below | `Ctrl + Alt + ↑` / `Ctrl + Alt + ↓` |
| Select all occurrences | `Ctrl + Shift + L` |
| Select current word | `Ctrl + D` |
| Expand selection | `Shift + Alt + →` |
| Column selection | `Shift + Alt + drag` |

## Search & Replace
| Action | Shortcut |
|--------|----------|
| Find | `Ctrl + F` |
| Replace | `Ctrl + H` |
| Find in files | `Ctrl + Shift + F` |
| Replace in files | `Ctrl + Shift + H` |
| Find next/previous | `F3` / `Shift + F3` |

## Navigation
| Action | Shortcut |
|--------|----------|
| Go to line | `Ctrl + G` |
| Go to file | `Ctrl + P` |
| Go to symbol | `Ctrl + Shift + O` |
| Go to definition | `F12` |
| Peek definition | `Alt + F12` |
| Back / Forward | `Ctrl + -` / `Ctrl + Shift + -` |
| Switch editor tab | `Ctrl + Tab` / `Ctrl + Shift + Tab` |

| Explorer | `Ctrl + Shift + E` |
| Search | `Ctrl + Shift + F` |
| Source control | `Ctrl + Shift + G` |
| Run / Debug | `Ctrl + Shift + D` |
| Extensions | `Ctrl + Shift + X` |

## Debugging
| Action | Shortcut |
|--------|----------|
| Start / Continue | `F5` |
| Stop | `Shift + F5` |
| Step over | `F10` |
| Step into | `F11` |
| Step out | `Shift + F11` |
| Toggle breakpoint | `F9` |

## Integrated Terminal
| Action | Shortcut |
|--------|----------|
| New terminal | `` Ctrl + ` `` |
| New terminal (with dir) | `` Ctrl + Shift + ` `` |
| Kill terminal | `Ctrl + K` then `Ctrl + C` |

## File Management
| Action | Shortcut |
|--------|----------|
| New file | `Ctrl + N` |
| Open file | `Ctrl + O` |
| Save | `Ctrl + S` |
| Save all | `Ctrl + K` `S` |
| Close tab | `Ctrl + W` |
| Reopen closed tab | `Ctrl + Shift + T` |
| Split editor | `Ctrl + \` |
