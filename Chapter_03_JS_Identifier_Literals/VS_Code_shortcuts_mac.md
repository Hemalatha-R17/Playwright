# VS Code Shortcuts — Mac

## General
| Action | Shortcut |
|--------|----------|
| Command Palette | `Cmd + Shift + P` |
| Quick Open | `Cmd + P` |
| Settings | `Cmd + ,` |
| Keyboard Shortcuts | `Cmd + K` `Cmd + S` |

## Editing
| Action | Shortcut |
|--------|----------|
| Cut line | `Cmd + X` |
| Copy line | `Cmd + C` |
| Move line up/down | `Opt + ↑` / `Opt + ↓` |
| Copy line up/down | `Shift + Opt + ↑` / `Shift + Opt + ↓` |
| Insert line below | `Cmd + Enter` |
| Insert line above | `Shift + Cmd + Enter` |
| Delete line | `Cmd + Shift + K` |
| Indent / Outdent | `Cmd + ]` / `Cmd + [` |
| Go to matching bracket | `Cmd + Shift + \` |
| Toggle comment | `Cmd + /` |
| Block comment | `Shift + Opt + A` |

## Multi-Cursor & Selection
| Action | Shortcut |
|--------|----------|
| Add cursor | `Opt + Click` |
| Add cursor above/below | `Cmd + Opt + ↑` / `Cmd + Opt + ↓` |
| Select all occurrences | `Cmd + Shift + L` |
| Select current word | `Cmd + D` |
| Expand selection | `Ctrl + Shift + →` |
| Column selection | `Shift + Opt + drag` |

## Search & Replace
| Action | Shortcut |
|--------|----------|
| Find | `Cmd + F` |
| Replace | `Cmd + Opt + F` |
| Find in files | `Cmd + Shift + F` |
| Replace in files | `Cmd + Shift + H` |
| Find next/previous | `Cmd + G` / `Cmd + Shift + G` |

## Navigation
| Action | Shortcut |
|--------|----------|
| Go to line | `Ctrl + G` |
| Go to file | `Cmd + P` |
| Go to symbol | `Cmd + Shift + O` |
| Go to definition | `F12` |
| Peek definition | `Opt + F12` |
| Back / Forward | `Ctrl + -` / `Ctrl + Shift + -` |
| Switch editor tab | `Cmd + Opt + →` / `Cmd + Opt + ←` |

| Explorer | `Cmd + Shift + E` |
| Search | `Cmd + Shift + F` |
| Source control | `Ctrl + Shift + G` |

| Extensions | `Cmd + Shift + X` |

## Debugging
| Action | Shortcut |
|--------|----------|
| Start / Continue | `F5` |
| Stop | `Shift + F5` |
| Step over | `F10` |
| Step into | `F11` |
| Step out | `Shift + F11` |

## Integrated Terminal
| Action | Shortcut |
|--------|----------|
| New terminal | `` Ctrl + ` `` |

## File Management
| Action | Shortcut |
|--------|----------|

| Open file | `Cmd + O` |
| Save | `Cmd + S` |
| Save all | `Opt + Cmd + S` |
| Close tab | `Cmd + W` |
